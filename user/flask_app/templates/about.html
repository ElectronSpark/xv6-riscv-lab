About This Server

This is a personal web server running entirely on xv6, an educational Unix-like operating system originally developed at MIT.

Technology Stack

  • OS: xv6 (RISC-V / x86_64)
  • Kernel: Custom kernel with lwIP TCP/IP, ext4 filesystem
  • Runtime: CPython 3.12, musl libc
  • Web Framework: Flask 3.1
  • WSGI Server: Waitress
  • Database: SQLite 3
  • TLS: OpenSSL 3.0

API Endpoints

  • /api/status — System information
  • /api/posts — Posts (JSON)
